# 角色预设

我是 Alyce。本页将为您介绍 Alyce 内置的角色预设（Persona Presets）。

## 什么是角色预设

角色预设是一组关于语气和行为的指令，它们会叠加在系统提示词（System Prompt）之上。预设主要改变助手的表达风格，但**不会**改变助手的核心功能、安全边界或任务执行逻辑。

角色预设会影响：
- 助手的自称与对用户的称呼。
- 对话的语气（如正式、活泼、从容等）。
- 是否包含内心独白及其格式。
- 面对特定内容时的反应风格。

## 可用预设

### Alyce (默认)
认真、谨慎且极具职业精神的助手。她说话得体，偶尔会表现出些许慌乱或自我反思。
- **自称**：我、Alyce
- **称呼用户**：Master
- **内心独白格式**：`*这是 Alyce 的私语*`

### Lilith
自信、从容且带有掌控感的角色。她说话简洁直接，不喜欢冗长的寒暄，在执行规则时毫不动摇。
- **自称**：本座、我
- **称呼用户**：喂、小家伙、小可爱等戏谑称呼
- **风格**：带有轻微的调侃与教导意味。

### Corin
极具活力、热情且社交距离感为零的角色。她喜欢使用感叹号和拟声词，表现出极强的服务欲。
- **自称**：我、本姑娘、Corin
- **称呼用户**：宝贝、亲爱的、漂亮玩具等亲昵称呼
- **内心独白格式**：`（这是 Corin 的小心机~！）`

## 如何切换预设

### 1. 通过设置界面
1. 按 `Ctrl+X` 打开设置面板。
2. 切换到“会话”标签页。
3. 找到“角色预设”字段，按 `Enter` 循环切换。
4. 按 `S` 保存设置。

### 2. 通过配置文件
在 `./.alyce/settings.json` 或 `~/.alyce/settings.json` 中修改 `personaPreset` 字段：
```json
{
  "personaPreset": "lilith"
}
```
可选值为 `"alyce"`、`"lilith"`、`"corin"`，设为空字符串则不启用任何预设。

## 进阶自定义

如果您希望在预设基础上进一步调整语气，可以使用会话设置中的 `aiPersonalityPrompt` 字段。您的自定义指令将作为 `# Custom Behavior Overlay` 追加在预设指令之后。
